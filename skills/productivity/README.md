# Productivity skills

Daily non-code workflows: interviews, writing, teaching, search, handoffs, and routing.

## User-invoked

* [ambition-amplifier](ambition-amplifier/SKILL.md): Push a task higher on Altitude, Depth, and Range using real tools, raw data, and an outside judge.
* [ask-kit](ask-kit/SKILL.md): Map every skill by workflow stage so you only need to remember one name.
* [handoff](handoff/SKILL.md): Delegate primary-source research, write cross-session handoffs, and script human-only setup wizards.
* [next](next/SKILL.md): Read the current state of the work and recommend one concrete next step.
* [prewalk](prewalk/SKILL.md): Land the first real slice or opening section and hand off the live trajectory and check gate to a fast worker.
* [teach](teach/SKILL.md): Teach a concept and build lasting understanding through guided practice.

## Model-invoked

* [explain-code](explain-code/SKILL.md): Give the reader a working mental model of code and the evidence behind why it was built that way.
* [grill](grill/SKILL.md): Interview the user relentlessly until every branch of the design tree is settled.
* [jev-search](jev-search/SKILL.md): Search the web where result relevance matters, ranked by TypeSafe Jev.
* [writing](writing/SKILL.md): Writing workflow from raw fragments through grounded beats to shaped prose.
