# Engineering skills

Daily software engineering workflows.

## User-invoked

* [agent-setup](agent-setup/SKILL.md): onboard a repository for agents and fix recurring session failures without a full rewrite.
* [bonsai](bonsai/SKILL.md): refactor a whole repo in five gated phases so boundaries, bans, and checks live in tools instead of prose.
* [fold-subagent](fold-subagent/SKILL.md): fold an unnecessary subagent, router, or specialist into skills and tools in the main loop.
* [retro](retro/SKILL.md): run a session retrospective and promote repeated corrections downward into deterministic checks.
* [ship](ship/SKILL.md): commit and push finished work cleanly across every touched repository.
* [spec-build](spec-build/SKILL.md): turn settled decisions into local specs, wayfinding maps, and vertical TDD slices.

## Model-invoked

* [agent-architecture](agent-architecture/SKILL.md): design, review, or simplify an AI agent or harness.
* [debug](debug/SKILL.md): empirical root-cause diagnosis and git merge or rebase conflict resolution.
* [design](design/SKILL.md): deep modules, domain models (`CONTEXT.md`, `docs/adr/`), and throwaway prototypes.
* [diff-review](diff-review/SKILL.md): verification-artifact-first code review and concise PR summaries.
* [skill-hygiene](skill-hygiene/SKILL.md): create, audit, deduplicate, or prune skills, tool descriptions, and system prompts.
* [ui-design](ui-design/SKILL.md): flows, states, in-place prototypes, visual tokens, and motion physics.
* [verify-artifacts](verify-artifacts/SKILL.md): Layer 3 runtime, browser, CLI, and visual verification artifacts and done-checking claimed work.
