# Scope

Skills in this kit change only for a failure observed in a real session.

- Add a skill when a repeated workflow needs its own trigger, steps, or references.
- Edit a skill when a real session hits a concrete failure, drift, or missing check.
- Reject speculative guardrails, synthetic benchmarks, and mega-skills that bundle unrelated jobs. Record rejected ideas in `.out-of-scope/` with the reason.
