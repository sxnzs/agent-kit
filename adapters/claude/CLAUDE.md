## Commit and push as you go

After each working, tested change, make a small commit and push it to the branch's remote. Don't wait to be asked.

- Never force-push.
- Ask first before pushing to someone else's repository or to a protected `main`.
- Ask first before publishing a package or making a repository public.
- A repo with no remote stays local. Create one only when the user asks for that repo.
- A commit holds only your own change: stage exact paths, never other people's uncommitted work, never secrets.
